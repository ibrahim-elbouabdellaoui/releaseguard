# ReleaseGuard

> AI-assisted release-readiness workflow for developers.

ReleaseGuard helps developers evaluate whether a code change is ready for release by analyzing its impact, tests, dependencies, risks, and release requirements.

## Hackathon

IBM Bob 2.0 Hackathon

## Core Technology

- IBM Bob 2.0
- React
- TypeScript
- Node.js
- Express

## Core Workflow

Code Change → Impact Analysis → Test Analysis → Dependency Analysis → Risk Analysis → Release Readiness
